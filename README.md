# Prueba de GitHub

## Descripción

Este repositorio fue creado con el propósito de realizar pruebas y validar el flujo de trabajo en GitHub, incluyendo la gestión de código fuente, control de versiones, ramas, pull requests y procesos de integración.

## Objetivo

El objetivo principal de esta prueba es:

- Validar la conexión con GitHub.
- Probar el proceso de commits y versionamiento.
- Evaluar la creación y gestión de ramas.
- Verificar el proceso de Pull Request y revisión de código.
- Confirmar la correcta sincronización entre el entorno local y el repositorio remoto.
